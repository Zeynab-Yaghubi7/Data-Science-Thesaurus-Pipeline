# Data Science Thesaurus Construction & Data Cleaning Pipeline

This repository contains the Python and R scripts developed for my Master's thesis research: *"Investigating the Evolution of Research Topics and Forecasting Future Topics in the Field of Data Science"*.

## Project Overview
Raw bibliometric data often suffer from lexical noise (singular/plural, acronyms, typos). This project implements an 8-stage data cleaning and thesaurus construction pipeline to standardize keywords and build a robust co-word network.

## Key Features
- **Python:** Scripts for structural normalization, noise removal, and semantic synonym detection using Sentence Transformers (all-mpnet-base-v2).
- **R:** Scripts for cleaning bibliographic data.
- **Validation:** Data quality validation scripts ensuring 98.7% precision.

## Data
The data used in this project was extracted from Web of Science and Scopus (15,172 unique articles).
